# GUI Application Shell (Wails)

This directory contains the Wails desktop application shell.

- **Backend**: Go shell wrapping application window, lifecycle, and connecting to the Go local HTTP API.
- **Frontend**: Scaffolding navigation (Dashboard, Scan Results, Duplicate Finder, Stale Files, Forecasting, Trash & Audit Log), action confirmation modals, and placeholder views for Sahil's data-driven visualizations.
